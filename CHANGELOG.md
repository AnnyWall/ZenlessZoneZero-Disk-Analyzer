# Changelog

Все значимые изменения в проекте будут документированы в этом файле.

## [2.1.0] - 2025-11-21

### 🎨 Улучшения UI
- Круглые аватары агентов
- Улучшенное отображение W-Engine иконок (120x120)
- Оптимизированная загрузка изображений

### 🐛 Исправления
- Исправлена обрезка W-Engine иконок по краям
- Исправлена проблема с удалением виджетов при асинхронной загрузке
- Улучшена обработка ошибок при загрузке изображений
- Исправлено масштабирование аватаров агентов


## [2.0.0] - 2025-11-20

### 🎨 Полная миграция на PyQt5
- Переписан весь интерфейс с CustomTkinter на PyQt5
- Значительно улучшена производительность и стабильность
- Устранены лаги и артефакты при прокрутке
- Плавная работа без зависаний

### ✨ Новые возможности
- 🔥 Добавлен ранг **SSS** для супер крутых сборок (диски ≥8.0, агенты ≥48)
- 💎 Интерактивные Core Skills с эффектом свечения при наведении
- 🎯 Улучшенное отображение характеристик без рамок
- 📐 Центрированное отображение основного стата и оценки дисков
- 🖼️ Увеличенные иконки W-Engine (120x120) без обрезки

### 🚀 Оптимизации
- Кэширование изображений на диск для мгновенной загрузки
- Connection pooling для HTTP запросов
- Автоматические повторы при ошибках загрузки
- Умная проверка кеша перед загрузкой
- Оптимизированная обработка изображений

### 🛠️ Технические улучшения
- Миграция с CustomTkinter на PyQt5
- Использование QThread для асинхронной загрузки
- Requests Session с retry стратегией
- Улучшенная обработка ошибок
- Автоматическая установка зависимостей

### 🗑️ Удалено
- Старые файлы CustomTkinter версии
- Неиспользуемые конфигурации производительности
- Устаревшие скрипты запуска

### 📦 Сборка
- Обновлен build.bat для PyQt5
- Новый .spec файл с правильными зависимостями
- Исключение tkinter из сборки

## [1.0.0] - 2025-11-19

### Добавлено
- ⚡ Неоновый дизайн интерфейса с киберпанк эстетикой
- 📊 Детальный анализ агентов с характеристиками
- 💎 Система рейтингов дисков (SS, S, A, B, C, D)
- 🎮 Визуализация Mindscape (созвездия) с кружками
- 💫 Визуализация Core Skills (пассивные навыки) с буквами A-F
- ⚔️ Отображение боевых навыков с эмодзи-иконками
- 🔧 W-Engine информация с динамической загрузкой иконок
- 🎨 Цветовая индикация качества по рангам
- 🚀 Оптимизированная производительность
- 💾 Кэширование данных и изображений
- 🖼️ Поддержка высокого DPI для Windows
- 📱 Адаптивный интерфейс с прокруткой

### Оптимизации
- Переиспользуемые объекты шрифтов
- Оптимизация рендеринга ScrollableFrame
- Батчинг загрузки изображений
- Debounce для изменения размера окна
- Кэширование API запросов (5 минут)

### Технологии
- CustomTkinter для GUI
- Flask для backend API
- enka.py для работы с Enka Network
- Pillow для обработки изображений
- Threading для асинхронной загрузки
